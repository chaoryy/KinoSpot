# КиноSpot

Мобильное приложение-агрегатор сеансов кинотеатров Кыргызстана: фильмы, расписание и цены в одном месте. Клиент написан на Flutter, данные приходят от собственного Java-сервера.

## Возможности

- Список фильмов с постерами, поиск по названию, фильтр по жанру
- Экран фильма: рейтинг, жанры, длительность, описание
- Сеансы по кинотеатрам и датам, фильтр по дате и кинотеатру
- Обработка ошибок (нет связи, ошибка сервера) с кнопкой «Повторить»

## Стек

- **Клиент:** Flutter, `flutter_bloc`, `http`, `cached_network_image`
- **Сервер:** Java 16+, `com.sun.net.httpserver`, Gson

## Структура

```
KinoSpot/
├── server/   Java-сервер
└── app/      Flutter-приложение (lib/data, lib/bloc, lib/ui)
```

## Как запустить

```bash
git clone https://github.com/chaoryy/KinoSpot.git
```

**1. Сервер.** Открой папку `server/` в IntelliJ IDEA и запусти `Main`. Сервер работает на порту 9889. Проверка: `http://localhost:9889/movies` в браузере должен показать JSON.

**2. Приложение.** Запусти эмулятор Android, затем:

```bash
cd app
flutter pub get
flutter run
```

Адрес сервера задан в `app/lib/data/api/api_service.dart` (`baseUrl = http://10.0.2.2:9889`). Адрес `10.0.2.2` это компьютер, на котором запущен эмулятор. На реальном телефоне замени его на IP компьютера в одной Wi-Fi сети.

Если приложение показывает ошибку сети, проверь, что сервер запущен.

## Архитектура

`ApiService` → `KinoSpotRepository` → `Bloc` → UI

- **ApiService** делает запросы и превращает JSON в модели.
- **KinoSpotRepository** даёт Bloc данные, Bloc не знает про сеть.
- **Bloc** получает события и выдаёт состояния (загрузка, успех, ошибка), UI их только показывает.

| Bloc | События | Состояния |
|---|---|---|
| `MoviesBloc` | `LoadMovies`, `SearchMovies`, `FilterByGenre` | загрузка, список, ошибки сети и сервера |
| `SessionsBloc` | `LoadSessions`, `SelectDate`, `SelectCinema` | загрузка, список, ошибка |

Фильтрация сеансов выполняется на клиенте: приложение загружает все сеансы фильма и отбирает нужные.

## API сервера

Только GET, ответ в JSON.

| Запрос | Описание |
|---|---|
| `/movies` | список фильмов |
| `/movies/{id}` | один фильм |
| `/movies/{id}/sessions` | сеансы фильма |
| `/sessions`, `/sessions/{id}` | сеансы |
| `/cinemas`, `/cinemas/{id}`, `/cinemas/{id}/sessions` | кинотеатры и их сеансы |

Приложение использует `/movies` и `/movies/{id}/sessions`. При ошибке сервер возвращает статус 400, 404 или 405 и текст вроде `NOT_FOUND`.

## Ограничения и планы

- Данные демонстрационные.
- Сервер только отдаёт данные, бронирования билетов нет.
- Планы: база данных вместо памяти (JDBC), фильтры на сервере, выбор мест и бронирование.
